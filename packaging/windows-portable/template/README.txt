七款小游戏 · Windows 便携版
============================

启动方法
--------
1. 请先完整解压 ZIP，不要直接在压缩包内运行。
2. 双击“开始游戏.cmd”。
3. 默认浏览器会打开统一游戏大厅。

本便携版支持 Windows 10 和 Windows 11。
不需要安装 Node.js、Python、npm，也不需要联网。

退出方法
--------
关闭启动游戏时出现的命令窗口，或在窗口内按 Ctrl+C。
浏览器页面随后无法继续加载，这是正常现象。

存档说明
--------
通关记录保存在浏览器的本地存储中。
建议始终使用同一个 Windows 用户和同一个浏览器游玩。
清理浏览器网站数据可能会删除游戏记录。

端口占用
--------
游戏固定使用本机端口 5200，以保证存档地址稳定。
如果提示端口被占用，请关闭之前启动的游戏窗口后重试。

Windows 安全提示
----------------
本包没有安装程序，不修改注册表，不写入系统目录。
启动脚本只在本机 127.0.0.1 上提供静态游戏文件。
如果 Windows 显示来自未知发布者的提示，请确认文件来自可信发送者。

文件完整性
----------
请保留“开始游戏.cmd”“server.ps1”“index.html”和“games”文件夹。
不要只复制单个游戏的 HTML 文件，否则游戏资源可能无法加载。
