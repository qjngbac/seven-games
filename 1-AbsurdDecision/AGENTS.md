# AGENTS.md — 《今天也要做决定》

这是一款**短局搞笑叙事决策**网页小游戏，不是普通问答页。核心价值来自「选择的代价、延迟反馈、事件因果、搞笑结果」，而不是页面数量或动画。

## 产品一句话
玩家扮演一个普通打工人，每天处理若干随机事件；每个选择改变 金钱 / 声誉 / 精神 / 技术债，并可能增加标签或预约未来事件。撑过规定天数即通关；任一核心资源跌破/突破阈值即触发对应失败结局。

## 架构铁律（任何新功能先回答这三个问题）
1. 它是否增加**判断**？（没有取舍的选择 = 坏设计）
2. 是否产生**可解释反馈**？（失败也要有笑点或原因）
3. 是否让**事件更容易扩展**？（内容必须数据驱动）

若三条都不满足，不应加入 MVP。

## 分层职责（绝不跨层）
- `src/core/`：**纯规则层，禁止依赖 DOM**。Rng（可复现随机）、state（状态构造/深拷贝）、resources（区间映射）、effects（效果事务：先校验后提交，失败回滚）、eventSelector（条件过滤+带权抽取+冷却+类别疲劳）、game（流程编排：选择结算/每日开始/结局）。
- `src/data/`：内容配置。`world.ts` 定义资源/关系/特质；`events/*.json` 是事件包；`schema.ts` 校验；`index.ts` 合并校验并**跳过非法事件（不崩溃）**。
- `src/stores/game.ts`：Pinia 状态机（BOOT→MAIN_MENU→ROLE_SELECT→DAY_START→EVENT_PRESENT→EVENT_RESULT→DAY_SUMMARY→ENDING）。**UI 只调用 actions，绝不直接改业务状态。**
- `src/services/`：save（localStorage + saveVersion + 事务写入 + 备份 + 迁移）、audio（WebAudio 合成音效，可关）。
- `src/components/`：纯展示组件，按 screen 切换。

## 关键不变式
- 同一 `seed` + 同一选择序列 ⇒ 完全相同事件与结算（测试可重放）。
- 抽到的事件**至少有一个可选选项**（否则视为死锁，兜底进日结）。
- 效果非法 ⇒ 回滚到快照，记日志，不残写半截状态。
- 资源变化自动钳制到合法区间；失败在资源越界时触发，且只触发一次。

## 验证
- `npm run typecheck` 类型检查
- `npm run test` 单元测试（core 规则层全覆盖）
- `npm run build` 生产构建
- 修改后必须实际跑测试；总结区分「已验证」与「未验证」。
